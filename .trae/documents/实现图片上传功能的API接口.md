# 图片上传功能API实现计划

## 分析现状
- 前端已实现用户头像展示功能，使用`user.avatar`字段
- 后端用户模型已有`avatar`字段，存储头像URL
- 后端已有用户资料更新接口，支持更新`avatar`字段
- 项目已安装`python-multipart`库，支持文件上传
- 缺少图片上传API和静态文件服务配置

## 实现步骤

### 1. 配置静态文件服务
- 在`main.py`中添加静态文件目录配置
- 创建`uploads`目录用于存储上传的图片
- 配置文件访问路径和安全设置

### 2. 实现图片上传API
- 在`app/api/`目录下创建`upload.py`模块
- 实现`/upload/image`端点，支持POST请求上传图片
- 处理文件验证、保存和URL生成
- 返回上传成功的图片URL

### 3. 增强用户资料更新API
- 修改`user.py`中的个人资料更新接口
- 支持通过文件上传方式更新头像
- 保持向后兼容，继续支持URL方式设置头像

### 4. 实现图片管理API
- 添加上传历史记录查询接口
- 实现图片删除功能
- 添加图片列表获取接口

### 5. 前端集成支持
- 提供图片上传的API文档
- 确保前端能够通过`FormData`格式调用上传接口
- 支持图片上传进度显示和错误处理

## 技术要点
- 使用FastAPI的`UploadFile`处理文件上传
- 实现文件类型验证，只允许图片格式
- 生成唯一文件名，避免冲突
- 配置静态文件服务，使上传的图片可通过HTTP访问
- 实现适当的错误处理和安全检查
- 保持API接口的一致性和可扩展性
