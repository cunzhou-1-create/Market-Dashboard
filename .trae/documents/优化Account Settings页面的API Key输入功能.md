# 优化Account Settings页面的API Key输入功能

## 实现计划

### 1. 实现明文/密文切换功能
- 在`Settings.jsx`中添加状态管理，用于控制API Key输入框的显示模式
- 实现点击visibility图标的切换逻辑
- 当切换到明文模式时，更改图标为visibility_off
- 当切换到密文模式时，更改图标为visibility

### 2. 增加添加其他接口功能
- 在Qwen LLM API Key部分下方添加"添加其他接口"按钮
- 实现点击按钮展开/收起其他接口输入区域的功能
- 添加其他常见LLM接口的输入框（如OpenAI、Anthropic等）
- 为每个接口输入框添加相同的明文/密文切换功能
- 为每个接口添加连接状态指示器

### 3. 静态界面优化
- 确保所有新增元素的样式与现有设计保持一致
- 优化布局和间距，确保界面美观
- 添加适当的过渡动画，提升用户体验
- 确保在深色模式下也能正常显示

### 4. 代码结构优化
- 合理组织代码，确保可维护性
- 提取重复的组件逻辑，如明文/密文切换功能
- 保持代码风格与现有代码一致

## 技术实现要点

- 使用React的useState钩子管理输入框的显示模式和展开状态
- 使用条件渲染实现展开/收起功能
- 复用现有的样式类和设计模式
- 确保所有交互元素都有适当的hover效果和过渡动画

## 预期效果

- 用户可以通过点击图标切换API Key的明文/密文显示
- 用户可以添加和配置多个LLM接口
- 界面保持美观和一致性
- 代码结构清晰，易于维护
