# 启动开发服务器验证完整前端和后端服务

## 项目结构分析
- **前端项目**：位于 `booking-main` 目录，使用 React + Vite 构建
- **后端项目**：位于 `backend` 目录，使用 FastAPI 框架

## 启动计划

### 1. 启动后端服务
- **路径**：`c:\Users\cunzhou\Desktop\coder\Market-Dashboard\backend`
- **方式**：运行 `start-backend.bat` 脚本
- **功能**：启动 FastAPI 后端服务，监听端口 8000
- **验证**：访问 `http://localhost:8000/docs` 检查 API 文档是否可访问

### 2. 启动前端服务
- **路径**：`c:\Users\cunzhou\Desktop\coder\Market-Dashboard\booking-main`
- **方式**：运行 `start-dev.bat` 脚本或执行 `npm run dev` 命令
- **功能**：启动 Vite 开发服务器，提供前端应用
- **验证**：访问前端服务地址（通常为 `http://localhost:5173`）检查应用是否正常加载

### 3. 验证完整服务
- **API 连接**：检查前端是否能正常连接到后端 API
- **功能测试**：验证关键功能如市场数据获取、用户认证等是否正常工作
- **错误处理**：检查是否有任何错误或警告信息

## 预期结果
- 后端服务成功启动并运行在端口 8000
- 前端服务成功启动并运行在开发端口
- 前端应用能够正常连接后端 API
- 所有核心功能能够正常工作

## 注意事项
- 确保网络连接正常
- 确保端口 8000 和前端开发端口未被占用
- 如遇依赖问题，根据错误信息安装相应依赖
