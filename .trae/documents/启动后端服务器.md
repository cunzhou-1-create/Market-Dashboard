# 启动后端服务器计划

## 1. 检查Python环境
- 验证系统中已安装Python 3.8+
- 检查pip是否可用

## 2. 安装项目依赖
- 在backend目录中执行：`pip install -r requirements.txt`
- 确保所有依赖包正确安装

## 3. 检查环境配置
- 确认.env文件存在且配置正确
- 验证数据库配置是否合适

## 4. 启动后端服务
- 方式1：直接运行`python main.py`
- 方式2：使用uvicorn命令`python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000`

## 5. 验证服务启动
- 检查服务是否在8000端口成功运行
- 访问`http://localhost:8000/health`验证健康检查端点
- 访问`http://localhost:8000/docs`查看API文档

## 6. 故障排查
- 如果启动失败，检查错误信息
- 确认端口未被占用
- 验证依赖是否完整安装
- 检查环境变量配置

## 预期结果
后端服务成功在8000端口运行，可通过API文档访问和测试各个接口。
