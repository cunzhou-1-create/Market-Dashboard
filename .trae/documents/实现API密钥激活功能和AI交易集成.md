# 实现API密钥激活功能和AI交易集成

## 问题分析
当前系统存在以下问题：
1. API密钥添加后只是存储，没有验证和激活功能
2. 前端显示连接状态，但后端没有实际验证API密钥的有效性
3. AI交易功能依赖于全局配置的API密钥，而非用户添加的密钥

## 实现计划

### 后端修改
1. **修改 `trade_service.py`**
   - 添加 `verify_api_key` 方法，根据提供商类型验证API密钥
   - 修改 `add_api_key` 函数，添加验证步骤并更新 `is_connected` 状态
   - 添加 `update_api_key_connection_status` 方法，用于更新连接状态

2. **修改 `ai_service.py`**
   - 修改配置获取逻辑，优先使用用户级别的API密钥
   - 添加用户API密钥管理功能
   - 确保AI交易信号生成和执行使用正确的API密钥

3. **修改 `api/settings.py`**
   - 确保API密钥管理接口能正确返回连接状态
   - 添加API密钥验证端点

### 前端修改
1. **修改 `Settings.jsx`**
   - 确保提交API密钥后能正确显示激活状态
   - 添加错误处理和用户反馈
   - 优化API密钥管理界面的用户体验

2. **修改 `services/api.js`**
   - 添加API密钥验证相关的API调用
   - 确保错误处理和状态管理

### 功能验证
1. 测试API密钥添加和激活流程
2. 测试AI交易功能是否能正确使用API密钥
3. 测试错误处理和边界情况

## 技术要点
- 使用环境变量和配置管理确保安全性
- 实现API密钥的哈希存储和验证
- 为不同API提供商实现专门的验证逻辑
- 确保前后端状态同步和用户体验

## 预期结果
- 用户在Settings页面添加API密钥后，系统会自动验证并显示激活状态
- AI交易功能能正确使用用户添加的API密钥
- 系统能处理无效API密钥的情况并给出明确的错误提示
