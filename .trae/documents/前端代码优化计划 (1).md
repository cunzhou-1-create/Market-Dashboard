# 前端代码优化计划

## 1. 代码结构优化

### 1.1 拆分大型文件
- **AppContext.jsx**: 将其拆分为多个专用上下文，如 `UserContext.jsx`、`MarketContext.jsx` 和 `SettingsContext.jsx`
- **Settings.jsx**: 提取内部的 `ApiKeyInput` 组件为单独的组件文件

### 1.2 提取共用组件
- 创建 `Header.jsx` 为共用头部组件，统一处理返回按钮和标题
- 创建 `TabNavigation.jsx` 为共用标签页导航组件

### 1.3 修复状态管理
- 在 `main.jsx` 中使用 `AppProvider` 包装应用，确保状态管理正常工作
- 移除组件中的默认值处理，因为 `useApp()` 应该始终返回有效的上下文

## 2. 冗余代码清理

### 2.1 移除未使用的组件和代码
- 移除未使用的 `PrivateRoute.jsx` 组件
- 清理 `App.jsx` 中重复的路由注释
- 移除组件中未使用的导入和变量

### 2.2 优化重复逻辑
- 在 `MainContent.jsx` 中提取重复的 `marketData.find()` 调用为变量
- 统一处理 `marketData` 为空的情况
- 优化 `Settings.jsx` 中的主题切换逻辑

### 2.3 功能整合
- 合并 `Navigation.jsx` 中的导航逻辑，确保与 `App.jsx` 中的路由一致
- 整合语言设置功能，确保 `LanguageSelector` 组件与 `Settings` 组件中的语言设置同步

## 3. 性能优化

### 3.1 减少不必要的渲染
- 使用 `React.memo` 包装纯展示组件
- 使用 `useMemo` 缓存计算结果，如 `marketData.find()` 的结果
- 优化 `AppContext.jsx` 中的状态更新，减少不必要的 localStorage 操作

### 3.2 优化数据获取
- 统一处理 `fetchMarketData` 等 API 函数，确保它们返回一致的数据格式
- 实现简单的数据缓存机制，减少重复的数据获取

## 4. 代码风格统一

### 4.1 命名规范
- 统一组件命名为 PascalCase
- 统一变量和函数命名为 camelCase
- 确保文件名与组件名一致

### 4.2 注释风格
- 统一注释语言为英文
- 添加必要的 JSDoc 注释
- 移除不必要的注释

### 4.3 代码格式
- 确保代码缩进一致
- 统一使用单引号或双引号
- 优化代码行长度，确保可读性

## 5. 功能完善

### 5.1 国际化
- 确保所有硬编码的文本都使用 `useTranslation` 钩子
- 补充缺失的翻译文本

### 5.2 功能完整性

### 5.3 错误处理
