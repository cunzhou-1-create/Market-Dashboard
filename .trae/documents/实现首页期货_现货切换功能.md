# 实现首页期货/现货切换功能

## 1. 修改 MarketContext.jsx
- 添加 `marketType` 状态，默认为 'spot'（现货）
- 添加 `setMarketType` 方法用于切换市场类型
- 添加模拟期货数据，结构与现货数据类似
- 修改数据获取逻辑，根据 `marketType` 返回对应的数据

## 2. 修改 MainContent.jsx
- 在页面左上方添加 "期货/现货" 切换按钮组
- 使用 `useState` 管理当前选中的市场类型
- 添加切换按钮的样式和交互逻辑
- 根据选中的市场类型显示对应的数据
- 确保切换按钮组的布局与现有设计风格一致

## 3. 数据处理
- 为期货数据创建模拟数据，包含主要期货合约
- 确保期货数据结构与现货数据保持一致，便于统一渲染
- 在切换市场类型时，更新显示的数据

## 4. 样式优化
- 确保切换按钮组的样式与现有设计风格匹配
- 响应式设计，适配不同屏幕尺寸
- 添加适当的动画效果，提升用户体验

## 5. 测试验证
- 验证切换功能是否正常工作
- 确保不同市场类型下数据显示正确
- 检查界面布局是否美观，无布局错乱问题

## 技术实现要点
- 使用 React 的 useState 和 useContext 管理状态
- 保持代码结构清晰，遵循现有代码风格
- 确保数据结构一致性，便于后续接入真实 API
- 优先完成静态界面显示，为后续功能扩展做好准备
